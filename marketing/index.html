Turn study material into lessons, quizzes, and podcasts.

Study Studio is a local-first, multi-provider AI learning application. It runs through Ollama, LM Studio, or any OpenAI-compatible local server (plus optional online providers) with Piper TTS for speech, and serves as the learning engine behind Helix Prime and Helix Education.

The product

Learning artifacts, generated locally

Study Studio keeps generation and speech local and provider-agnostic, with audio created when it is requested.

Structured learning

Generate lessons, quizzes, and glossaries from a topic or study material.

Podcast generation

Create podcasts with four real voices, including Arabic (Jordanian).

Audio export

Export generated audio on demand as MP3 or WAV.

Multi-provider runtime

Auto-detects local runtimes (Ollama, LM Studio, LocalAI, vLLM, LiteLLM, FastChat) and optional online providers (OpenAI, OpenRouter), with a live provider selector on the Generate page.

The Helix ecosystem

Learning engine for Helix Prime and Helix Education

Study Studio is a standalone, independently versioned repository. Helix Prime uses it as its AI lesson, quiz, and podcast generation engine; Helix Education consumes its quiz and evaluation event stream. Study Studio stays separate so it can be versioned and released on its own.

Build locally

Desktop and mobile development

Desktop

Use the Tauri desktop application.

cd apps/desktop
npm install
npm run tauri:dev

Mobile

Use the Expo mobile application.

cd apps/mobile
npm install
npm start

Local dependencies

A local AI runtime (Ollama, LM Studio, or another OpenAI-compatible server) is required for generation. Piper TTS and ffmpeg are optional for audio export; MP3 export requires ffmpeg.
