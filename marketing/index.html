Local-first learning

A private learning workspace that runs where you do.

Study Studio turns topics into lessons, quizzes, glossaries, podcasts, and audio using local model runtimes such as Ollama or LM Studio.

Current status: Actively used personal product. Desktop workflow is functional; mobile and optional audio setup remain in progress.

What this project demonstrates

Learn locally

Generation can run through a local model runtime without a hosted AI dependency.

Practice and remember

Lessons, quizzes, glossaries, and audio support repeated learning.

Affordable by default

The product explores useful learning on modest hardware and without mandatory subscriptions.

Evidence before ambition

This project is presented with a clear boundary: what is implemented, what is experimental, and what still requires external validation. It is part of a local-first portfolio built by Hatem Ismail Shalaby.
