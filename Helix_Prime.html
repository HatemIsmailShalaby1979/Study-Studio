Local AI learning

Lessons, quizzes, glossaries, and podcasts from your study material.

Study Studio is local-first and multi-provider: it runs through Ollama, LM Studio, or any OpenAI-compatible local server, with optional online providers, and Piper TTS for speech. It is an external sibling service in the Helix Codex ecosystem, not a library and not a dependency of Helix Prime. Version 0.2.0 is in development; build it from source with the steps below.

Features

Built around local generation

Lessons and quizzes

Turn a topic or study material into structured learning content.

Podcasts and voices

Generate podcasts with four real voices, including Arabic (Jordanian).

On-demand export

Create MP3 or WAV audio files when requested.

Multi-provider runtime

Auto-detects local runtimes (Ollama, LM Studio, LocalAI, vLLM, LiteLLM, FastChat) and optional online providers (OpenAI, OpenRouter), with a live provider selector on the Generate page.

The Helix ecosystem

A sibling service, not a component of Helix Prime

Study Studio is a standalone, independently versioned repository. An earlier revision of this page called it "the learning engine behind Helix Prime and Helix Education", which had the relationship backwards. Helix Prime's own contract documentation is explicit that its siblings are external services, not libraries, and that the integration surface is versioned event contracts only — importing sibling code or reading a sibling's datastore directly is prohibited. The one contract involving Study Studio is AssessmentCompleted, an outbound event that Helix Prime may ingest. Study Studio stays separate so it can be versioned and released on its own.
