Working / Local-first / Offline

A private AI tutor that runs on your machine.

Built solo, self-learning, while switching careers. No subscription. No data to cloud. Structured lessons, quizzes, glossaries, and bilingual podcasts — all against local models.

Verified: 46 test suites passed, 973 tests passed, 85.5% statement / 74.8% branch coverage, typecheck clean, lint clean, design-token guard clean, version drift clean at 0.2.0.

Why this exists

Alternatives force a false choice: pay per token for a hosted tutor, or paste prompts into a chat and hope. Neither is a study tool. Both leak your material. Study Studio keeps the model, the lesson, and the quiz on your machine — because learning is private.

What it does

  • Structured lessons (sections, glossary, quiz)
  • Bilingual podcast scripts (English / Arabic)
  • Quiz with local scoring + optional AI evaluation
  • Piper TTS → MP3/WAV export (needs ffmpeg)
  • Multi-provider runtime (LM Studio, Ollama, OpenAI-compatible)
  • On-demand model load (no preloading)
  • Learning Journey (progress, streaks, scores)
  • Library in IndexedDB with legacy migration

Honest boundary

Generation needs a local model runtime. Audio needs Piper voice files plus ffmpeg. There is no "it just works with zero setup" claim — because that would be false on a clean machine.
